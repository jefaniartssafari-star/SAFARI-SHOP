# 🛍️ SAFARI SHOP - Boutique en ligne

Bienvenue sur le dépôt officiel de **SAFARI SHOP**, une boutique en ligne statique, moderne et ultra-rapide. 
Ce projet a été conçu pour permettre aux commerçants de présenter leurs produits et de recevoir des commandes directement via WhatsApp, sans avoir besoin d'une base de données complexe ou d'un système de paiement lourd.

## ✨ Fonctionnalités

*   **Catalogue dynamique** : Affichage des produits avec images, prix, réductions et descriptions.
*   **Recherche instantanée** : Trouvez un produit en tapant son nom.
*   **Filtrage par catégorie** : Triez les produits (Audio, Accessoires, Informatique).
*   **Panier interactif** : Ajoutez, modifiez la quantité ou supprimez des articles.
*   **Commande via WhatsApp** : Génération automatique d'un message formaté avec le récapitulatif du panier et le total, envoyé directement sur WhatsApp.

## 🛠️ Technologies utilisées

Ce projet a été développé en utilisant uniquement les technologies web de base (pas de framework) pour garantir une légèreté et une rapidité maximales :
*   **HTML5** : Structure sémantique.
*   **CSS3** : Design moderne (Dark Mode), responsive (adapté aux mobiles) et animations.
*   **JavaScript (Vanilla)** : Logique du panier, filtrage et intégration de l'API WhatsApp.
